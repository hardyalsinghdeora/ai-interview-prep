# Question Lists by Skill

Practice lists for one technology or skill at a time: 55 skills and 2,199 questions. They complement the round-based banks in [topics/](../README.md#shared-topics-by-interview-round) and the [role guides](../roles/README.md).

Each list has five levels: fundamentals, working depth, senior / principal depth, scenarios and hands-on checks. It ends with what a strong answer shows and a small project to prove the skill.

> These are question lists without model answers. Look up unfamiliar terms in the [cheatsheets](../cheatsheets/README.md), and find worked answers on many of these subjects in [topics/](../README.md#shared-topics-by-interview-round). Items marked *(verify)* can change, so check them against current documentation.

## How to use these lists

1. Tick a question only when you can answer it **out loud in two minutes**, with a real example.
2. For a skill you're new to, do the **Prove it** project first. One real build teaches more than ten memorised answers.
3. Turn your best answers into interview stories using the [story bank checklist](../topics/00-overview/README.md#story-bank-checklist-prepare-one-story-for-each).
